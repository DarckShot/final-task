# Подготовка сдачи

Создайте одну тему: **sergey_krasn — Краснопольский Сергей Вячеславович**.
Исправления размещайте ответами в этой теме. Заполните шаблон перед публикацией:

```text
HTTPS: https://triadmind.ru/
Автор: Краснопольский Сергей Вячеславович, sergey_krasn
СУБД: PostgreSQL 17
Площадка: личный сервер
Исходники: https://github.com/DarckShot/final-task/tree/<git rev-parse HEAD>
README: https://github.com/DarckShot/final-task/blob/<тот-же-commit>/README.md
Доступы API и БД отправлены преподавателю личным сообщением в Moodle.
```

Последнюю строку добавьте **только после фактической отправки**. Приложите
package.json, package-lock.json, .env.example и db/001_tasks.sql. Действующий .env
не прикладывайте. Убедитесь, что именно этот commit развёрнут на сервере.

В личное сообщение преподавателю отправьте HTTPS-адрес, отдельный API-токен,
имя БД, роль tasks_reviewer и её пароль. Для согласованного SSH-туннеля добавьте
адрес/порт SSH, пользователя tasks-tunnel и команду подключения. Приватный SSH-ключ
преподаватель хранит у себя; используйте его публичный ключ. Не сообщайте пароль
Moodle, ИСУ, основной SSH или владельца БД.

Ручное дело в manual, SQL CRUD, перезапуск и HTTPS проверены 22.11.2026. До
публикации темы остаются внешний вход преподавателя в БД, сверка профиля Moodle,
приватная отправка доступов и проверка состава коммита.

Оставшиеся шаги:

1. Сверить ФИО/логин с собственным профилем Moodle.
2. Согласовать ограниченный туннель и проверить вход преподавателя с другой машины.
3. Приватно передать API-токен и реквизиты tasks_reviewer через Moodle.
4. Опубликовать одну тему с реальным URL и точным commit, приложить четыре файла.

Для точной ссылки получите `git rev-parse HEAD` в том checkout, из которого
собран контейнер. Не публикуйте шаблон с незаполненными полями и не отмечайте
отправку реквизитов заранее. Сравнение площадок и исследование Helios находятся
в README и docs/hosting.md; платные облачные услуги ради сравнения не требуются.
